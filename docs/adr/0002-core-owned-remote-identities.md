# ADR 0002：Core 统一拥有管理员与远程用户身份

## 状态

已接受。

## 决策

Rust Core 是管理员密码、远程用户、密码哈希、会话撤销与设备授权的唯一事实源。Go Web 服务通过仅限本机 stdio 的 `remote.admin.*` IPC 调用 Core，只在内存中维护浏览器随机会话与对应的 Core 管理员令牌，不持久化账户或密码。

Web 登录只接收内置 `admin` 管理员。普通用户仅供 QUIC/TLS 1.3 远程控制客户端使用，即使凭据有效也不能进入 Web 后台。Core 的公网 QUIC 入口反向拒绝内置管理员登录，避免管理身份跨网络暴露。

管理员在 Web 设置中创建、删除、重置远程用户，并按设备硬件身份分配访问范围。新增授权只允许选择当前在线设备；设备离线后仍可撤销历史授权。

## 原因

- 消除 Web 与 Core 两套密码库造成的密码漂移和迁移风险；
- 管理身份与远程操作身份职责分离；
- 设备授权最终由执行命令的 Core 强制校验，不能被前端绕过；
- 管理员改密和远程用户重置可在同一处撤销旧会话。

## 影响

首次启动仍使用 `admin/admin`。实际 TCP 回环来源可在 Core 仍使用初始密码时进入本机初始化流程；其他来源必须显式登录并立即改密。旧版本的 `credentials.json` 不再读取；升级后的有效管理员密码以 Core 远程数据目录中的 `accounts.json` 为准。
